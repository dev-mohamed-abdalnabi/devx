# ذكر Supabase backend

The community backend is defined in `migrations/20261002_community_backend.sql`.

It covers:

- Auth profile creation from `auth.users`
- Profiles, public/follower/group text posts
- Comments, likes, shares and following
- Public/private groups and membership requests
- Notifications generated by database triggers
- Reports with moderation status and admin visibility
- Counter maintenance triggers and indexes
- Row Level Security policies for every table

## Apply

1. Reconnect the Supabase connector and select the project used by the app.
2. Apply the migration once through the Supabase SQL editor or migration tooling.
3. Configure Auth email confirmation and redirect URLs for the Android package.
4. Build with fresh public client values:

```bash
flutter build apk --release \
  --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co \
  --dart-define=SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLISHABLE_KEY
```

Only the URL and publishable/anon key belong in the mobile app. Never use or ship a `service_role` key.
