# حزم تلاوات القرآن

ضع ملفًا باسم `quran.zip` داخل كل مجلد قارئ:

- `mishary/quran.zip` — مشاري راشد العفاسي
- `husary/quran.zip` — محمود خليل الحصري
- `minshawi/quran.zip` — محمد صديق المنشاوي
- `sudais/quran.zip` — عبدالرحمن السديس

داخل كل ZIP يجب أن تكون ملفات السور الصوتية مرقمة من `001.mp3` إلى `114.mp3`، ويمكن أن تكون داخل مجلد فرعي. الامتدادات المدعومة: `mp3`, `m4a`, `ogg`, `opus`.

هذه المجلدات تحفظ نسخ ZIP المصدرية داخل المستودع الخاص. التطبيق لا يستطيع تنزيلها مباشرة من GitHub الخاص؛ يجب رفع كل ZIP أيضًا على استضافة عامة وإضافة رابطه في `QuranAudioProvider`.

التطبيق ينزّل الـZIP العام بعد التثبيت إلى مساحة التطبيق الخاصة، ويتحقق من أن حجمه لا يتجاوز 100MB، ثم يفك الملفات خارج الـAPK. لا يتم تضمين أي ملف صوتي داخل حزمة التطبيق.
